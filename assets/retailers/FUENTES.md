# Logos de retailers

SVG tomados de las colecciones de Iconify (paquete npm `@iconify/json`).
Las marcas pertenecen a sus dueños; se usan solo para identificar a cada comercio en la presentación académica.

| Logo | Colección:ícono | Licencia de la colección |
|---|---|---|
| amazon | `thesvg-color:amazon` | MIT (theSVG Color) |
| mercadolibre | `thesvg-color:mercado-libre` | MIT (theSVG Color) |
| flipkart | `simple-icons:flipkart` | CC0 1.0 (Simple Icons) |
| shopee | `thesvg-color:shopee` | MIT (theSVG Color) |
| mediamarkt | `thesvg-color:mediamarkt` | MIT (theSVG Color) |
| bestbuy | `thesvg-color:best-buy` | MIT (theSVG Color) |
| saturn | `thesvg-color:saturn` | MIT (theSVG Color) |
| komplett | `selfhst:komplett` | CC BY 4.0 (selfh.st/icons) |
| darty | `thesvg-color:darty` | MIT (theSVG Color) |
| otto | `thesvg-color:otto` | MIT (theSVG Color) |
| coppel | `thesvg-color:coppel` | MIT (theSVG Color) |

`flipkart` es monocromo y se pinta #2874F0.

Para regenerar los PNG: `node canva/extraer/logos_png.js`.

Los comercios sin logo en esas colecciones (Lazada, bol., Euronics, Alza, Falabella, Ripley, Cdiscount, Trendyol, Kroger, Teknosa, takealot, Philips y las cadenas regionales) se componen como logotipo de texto en el color de la marca (`antecedentes_pm.GRUPOS`); en Canva se pueden reemplazar por el logo oficial.
